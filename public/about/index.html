About LinuxTerminal.me

LinuxTerminal.me is an educational environment for learning Linux by doing.

Simulator vs real Linux

The learning simulator is explicitly simulated. The Real Linux Lab is a separate browser VM experience. Telemetry is labelled REAL or SIMULATED so educational values are not presented as host measurements.

Safety philosophy

Sessions should be isolated, time-limited, and resource-bounded. The simulator is designed for experimentation without access to the host filesystem.

AI Tutor

The planned tutor uses learner context, terminal results, assessment evidence, and lesson state to give useful explanations and hints rather than guessing from screen text.

Technology

The project combines browser terminal UI, a deterministic learning engine, and a WebAssembly x86 VM path for realistic Linux practice.
