df

Report Filesystem Disk Space

Reports available and used space on mounted filesystems.

💡 Definition

df reports filesystem capacity and free space.

Use -h for human-readable units.

⌘ Syntax

df [options] [path...]
  • df -h /
  • df --help
  • man df

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead options and paths.
  2. InspectQuery mounted filesystem statistics.
  3. CalculateFormat used, available and capacity values.
  4. OutputWrite the filesystem table.
  5. ExitReturn a status.

▣ Key Concepts Explained

  • ✓
    Mounted filesystems

    df reports filesystem statistics rather than arbitrary directory trees.

  • ✓
    Capacity

    Size, used and available values describe storage allocation.

  • ✓
    Human-readable

    -h uses readable units.

  • ✓
    Exit status

    Scripts can inspect $?.
