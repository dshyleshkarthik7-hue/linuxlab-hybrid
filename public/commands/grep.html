grep

Search Text by Pattern

Searches input for lines matching a pattern.

💡 Definition

grep filters text using a search pattern.

Options such as -n, -i and -r change matching and display.

⌘ Syntax

grep [options] pattern [file...]
  • grep -n "error" app.log
  • grep --help
  • man grep

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead pattern, options and files.
  2. ValidateOpen input and compile the pattern.
  3. ExecuteCompare input lines with the pattern.
  4. OutputMatching lines go to stdout.
  5. ExitStatus distinguishes match/no-match/error.

Common Examples

Command Output Example

$ grep -n "error" app.log
42:error: connection refused
$ echo $?
0

What does the output look like?

Matching lines are printed. Exit status is also meaningful: a match, no match and an error are distinct outcomes.

▣ Key Concepts Explained

  • ✓
    Regular expressions

    Patterns can describe more than literal text.

  • ✓
    Pipelines

    grep commonly filters another command's output.

  • ✓
    Exit status

    0 means a match was found; other values have documented meanings.

  • ✓
    Recursive search

    -r can search directory trees.
