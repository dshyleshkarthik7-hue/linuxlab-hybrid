cd

Change Directory

Changes the shell's current working directory to a specified path. This guide covers practical usage, expected output and safe practice.

💡 Definition

cd changes the shell's current working directory.

Understand inputs, operation, output and exit status.

⌘ Syntax

cd [directory]
  • cd /var/www
  • cd --help
  • help cd

▶ Quick Use

Try it in our Linux Terminal

Run the example and inspect the result.

Open Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputThe shell reads the command and path.
  2. ValidateThe shell checks whether the destination is usable.
  3. ExecuteThe shell updates its working directory.
  4. OutputSuccessful directory changes normally print nothing.
  5. ExitThe shell records success or failure for scripts.

Command Output Example

$ pwd

$ echo $?
0

What does the result look like?

cd is a shell builtin, so a successful change usually has no stdout. Use pwd to inspect the new location.

▣ Key Concepts Explained

  • ✓
    Relative paths

    Use paths relative to the current directory.

  • ✓
    Home

    ~ expands to the current user's home directory.

  • ✓
    Exit status

    Scripts can inspect $?.

  • ✓
    Shell builtin

    The shell changes its own state, rather than a child process changing it.
