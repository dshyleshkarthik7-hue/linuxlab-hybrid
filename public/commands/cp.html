cp

Copy Files and Directories

Copies files or directories from one location to another.

💡 Definition

cp copies filesystem entries.

Use -r for directories and verify destinations before overwriting.

⌘ Syntax

cp [options] source destination
  • cp report.txt backup/
  • cp --help
  • man cp

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead source, destination and options.
  2. ValidateCheck paths, permissions and conflicts.
  3. ExecuteRead the source and create the destination.
  4. OutputErrors go to stderr when a copy fails.
  5. ExitReturn a status for scripts.

What does the result look like?

Successful copies normally produce no stdout. Verify the destination and use checksums when content integrity matters.
