top

Monitor Processes in Real Time

Displays a live, updating view of processes and system resource usage.

💡 Definition

top provides a continuously refreshed process and resource view.

It is useful for observing changing CPU and memory use.

⌘ Syntax

top [options]
  • top
  • top -h
  • man top

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. StartParse startup options.
  2. CollectRead process and resource counters.
  3. RefreshRe-read statistics at intervals.
  4. DisplayRender a live process table.
  5. ExitReturn when the monitor is closed.
