mv

Move or Rename Files

Moves files and directories or changes their names.

💡 Definition

mv changes the location or name of filesystem entries.

A same-filesystem move can update directory entries without copying file data.

⌘ Syntax

mv [options] source destination
  • mv draft.txt final.txt
  • mv --help
  • man mv

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead source and destination.
  2. ValidateCheck paths, permissions and conflicts.
  3. ExecuteRename or move the entry.
  4. OutputErrors are reported on stderr.
  5. ExitReturn a status for scripts.
