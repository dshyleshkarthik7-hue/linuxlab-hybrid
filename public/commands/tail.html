tail

Show the End of Files

Prints the last part of files or streams and can follow growing files.

💡 Definition

tail previews the end of files and can follow appended data.

Use -n for line count and -f for follow mode.

⌘ Syntax

tail [options] [file...]
  • tail -f app.log
  • tail --help
  • man tail

⚙ How It Works (Internal Process)

  1. Parse inputRead options and input files.
  2. Open inputRead the requested stream or file.
  3. Select suffixKeep the requested final records.
  4. FollowWith -f, wait for appended data.
  5. ExitReturn when complete or stopped.

▣ Key Concepts Explained

  • ✓
    Follow mode

    -f keeps watching for appended data.

  • ✓
    Line count

    -n controls how many final lines are printed.

  • ✓
    Live logs

    tail is useful for observing application logs as they grow.

  • ✓
    Exit status

    Scripts can inspect $? after the command exits.
