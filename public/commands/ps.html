ps

Report Running Processes

Displays information about active processes.

💡 Definition

ps reports process information for the current or selected processes.

Common options show process IDs, users, states and commands.

⌘ Syntax

ps [options]
  • ps aux
  • ps --help
  • man ps

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead process-selection and display options.
  2. CollectRead process information exposed by the OS.
  3. FormatSelect columns and format the report.
  4. OutputWrite the process table to stdout.
  5. ExitReturn a status for scripts.

▣ Key Concepts Explained

  • ✓
    PID and state

    Process IDs identify processes; state columns summarize status.

  • ✓
    Selection

    Options control which processes appear.

  • ✓
    Output

    Reports can be piped into other commands.

  • ✓
    Exit status

    Scripts can inspect $?.
