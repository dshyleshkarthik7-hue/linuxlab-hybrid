mkdir

Create Directories

Creates one or more new directories in the filesystem.

💡 Definition

mkdir creates directories.

The -p option can create missing parent directories.

⌘ Syntax

mkdir [options] directory...
  • mkdir -p projects/linux
  • mkdir --help
  • man mkdir

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead command, options and directory names.
  2. ValidateCheck parent path and permissions.
  3. ExecuteCreate the requested directory entries.
  4. OutputSuccessful runs normally print nothing.
  5. ExitReturn a status for scripts.
