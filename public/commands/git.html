git

Distributed Version Control

Records changes to files and coordinates work across repositories.

💡 Definition

git manages repositories, commits, branches and working trees.

Subcommands such as status, add, commit and log inspect or change repository state.

⌘ Syntax

git [options] command [args]
  • git status
  • git --help
  • git help

▶ Quick Use

⚙ How It Works (Internal Process)

  1. Parse inputRead the Git subcommand and arguments.
  2. Locate repositoryFind the repository metadata and working tree.
  3. Inspect or updatePerform the selected repository operation.
  4. OutputReport status, changes or history.
  5. ExitReturn a status for scripts.
