ping

Check Network Connectivity

Sends ICMP echo requests to test reachability and measure round-trip time.

💡 Definition

ping sends echo requests and reports replies and timing.

Packet loss and round-trip time help characterize connectivity.

⌘ Syntax

ping [options] <destination>
  • ping -c 4 8.8.8.8
  • ping --help
  • man ping

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse destinationThe program reads the target and options.
  2. Build requestAn ICMP echo request is prepared.
  3. Send packetThe operating system transmits the request.
  4. Receive replyReplies are timed and summarized.
  5. ExitThe final status reflects the observed result.

What does a packet look like?

A simplified echo request consists of an IP packet carrying an ICMP message. Exact headers, payload sizes and fields vary by implementation.

IP headerICMP headerPayload
$ ping -c 4 8.8.8.8

64 bytes from 8.8.8.8: icmp_seq=2 ttl=117 time=23.8 ms

4 packets transmitted, 4 received, 0% packet loss

▣ Key Concepts Explained

  • ✓
    ICMP and RTT

    ICMP echo messages can measure round-trip time.

  • ✓
    Packet loss

    Missing replies can indicate filtering, congestion or reachability issues.

  • ✓
    TTL

    The IP time-to-live field limits packet lifetime across routers.

  • ✓
    Exit status

    The final status depends on the command implementation and observed replies.
