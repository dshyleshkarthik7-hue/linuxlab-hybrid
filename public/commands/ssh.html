ssh

Secure Remote Login

Connects to a remote system using the Secure Shell protocol.

💡 Definition

ssh establishes an encrypted remote shell connection.

Keys and authentication methods determine access.

⌘ Syntax

ssh [options] [user@]host
  • ssh user@server
  • ssh -V
  • man ssh

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead user, host, port and options.
  2. ConnectEstablish a TCP connection to the SSH service.
  3. AuthenticateNegotiate keys and authenticate the user.
  4. SessionOpen a remote shell or requested channel.
  5. ExitClose the session and return a status.

▣ Key Concepts Explained

  • ✓
    Keys and authentication

    SSH can authenticate with passwords, keys and other configured methods.

  • ✓
    Encryption

    The SSH protocol protects session traffic.

  • ✓
    Host keys

    Clients use host keys to identify servers.

  • ✓
    Exit status

    Scripts can inspect $? after non-interactive SSH commands.
