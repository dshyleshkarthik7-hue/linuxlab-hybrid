sed

Stream Editor

Processes text streams using programmable editing commands.

💡 Definition

sed applies editing scripts to text streams.

It can transform data without opening an interactive editor.

⌘ Syntax

sed [options] 'script' [file...]
  • sed 's/dev/prod/g' config.txt
  • sed --help
  • man sed

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead the script and input stream.
  2. ValidateParse editing commands.
  3. ExecuteApply the script to input.
  4. OutputWrite transformed text to stdout.
  5. ExitReturn a status for scripts.
