ip

Inspect and Configure Networking

Shows and manages network interfaces, addresses, routes and related objects.

💡 Definition

ip displays and manages Linux networking objects.

Common objects include addr, link and route.

⌘ Syntax

ip [options] object command
  • ip addr show
  • ip help
  • man ip

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead object, command and options.
  2. ValidateCheck syntax and required privileges.
  3. ExecuteQuery or update networking state.
  4. OutputPrint interfaces, addresses, routes or errors.
  5. ExitReturn a status.
