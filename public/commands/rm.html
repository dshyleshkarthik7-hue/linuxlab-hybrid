rm

Remove Files and Directories

Removes directory entries and, with appropriate options, directories.

💡 Definition

rm removes filesystem entries.

Check paths carefully before using recursive or force options.

⌘ Syntax

rm [options] file...
  • rm old-notes.txt
  • rm --help
  • man rm

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead paths and options.
  2. ValidateCheck targets and permissions.
  3. ExecuteRemove directory entries.
  4. OutputErrors are written to stderr.
  5. ExitReturn a status for scripts.
