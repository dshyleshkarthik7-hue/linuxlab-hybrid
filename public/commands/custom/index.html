COMMAND LAB

Create Your Own Linux Command

Turn a repeated task into a reusable shell command. Start with an alias for a simple shortcut, a shell function when arguments are needed, or a script when the workflow deserves its own file.

Choose the right form

Alias

Best for a short replacement or option bundle.

alias ll='ls -la'

Shell function

Best when your command needs arguments or multiple steps.

mkcd() { mkdir -p "$1" && cd -- "$1"; }

Script

Best for a repeatable workflow that should be version-controlled and documented.

#!/bin/sh
set -eu
printf '%s\\n' "My custom command"

Safe workflow

  1. Give the command a clear name that does not shadow an important system command.
  2. Validate arguments before changing files or system state.
  3. Quote paths and user-provided values correctly.
  4. Use explicit exit statuses and document expected input/output.
  5. Test it in the LinuxTerminal simulator first, then use the real VM when kernel or distro behavior matters.
