curl

Transfer Data with URLs

Transfers data to or from servers using URL-based protocols.

💡 Definition

curl transfers data using URLs and supported network protocols.

It can inspect headers, download content and send common HTTP requests.

⌘ Syntax

curl [options] URL
  • curl -I https://example.com
  • curl --help
  • man curl

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead URL, protocol and request options.
  2. ResolveResolve the destination and establish a connection.
  3. TransferSend and receive protocol data.
  4. OutputWrite headers or response data as requested.
  5. ExitReturn a status describing the transfer.
