du

Estimate File Space Usage

Estimates the space used by files and directories.

💡 Definition

du estimates disk space consumed by directory entries.

Use -s for a summary and -h for readable units.

⌘ Syntax

du [options] [path...]
  • du -sh projects/
  • du --help
  • man du

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead paths and display options.
  2. TraverseWalk files and directories.
  3. MeasureEstimate allocated space according to filesystem metadata.
  4. OutputPrint totals and optional per-entry values.
  5. ExitReturn a status.

▣ Key Concepts Explained

  • ✓
    Recursive totals

    Directory usage includes entries below the requested path.

  • ✓
    Summary

    -s reports a total rather than every entry.

  • ✓
    Human-readable

    -h uses readable units.

  • ✓
    Filesystem allocation

    Reported usage is not always identical to apparent file size.
