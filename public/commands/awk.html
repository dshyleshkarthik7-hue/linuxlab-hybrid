awk

Pattern Scanning and Processing

Processes structured text by matching patterns and executing actions.

💡 Definition

awk processes records and fields using patterns and actions.

Whitespace-separated fields are exposed as $1, $2, and so on by default.

⌘ Syntax

awk 'pattern { action }' [file...]
  • awk '{print $1}' users.txt
  • awk --help
  • man awk

▶ Quick Use

Try it in our Linux TerminalOpen Linux Terminal ›

⚙ How It Works (Internal Process)

  1. Parse inputRead the program and input records.
  2. Split fieldsFields are separated according to the field separator.
  3. MatchEvaluate the pattern for each record.
  4. ActionExecute the action for matching records.
  5. ExitReturn a status for scripts.
