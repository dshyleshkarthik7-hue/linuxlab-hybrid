tar

Archive Files

Creates or extracts archive files, commonly used for backups and distribution.

💡 Definition

tar creates and extracts archive files.

Compression can be added with formats such as gzip.

⌘ Syntax

tar [options] archive [files...]
  • tar -czf site.tar.gz site/
  • tar --help
  • man tar

⚙ How It Works (Internal Process)

  1. Parse inputRead archive mode, name and file paths.
  2. ValidateCheck archive and input paths.
  3. ExecuteRead or write archive records.
  4. OutputList or extract entries as requested.
  5. ExitReturn a status.

Command Output Example

$ ls site.tar.gz

$ echo $?
0

What does the output look like?

    Create and extract

  • ✓
    Compression

    Flags such as -z commonly select gzip compression.

  • ✓
    Archive listing

    -t can inspect contents without extraction.

    Exit status

    Scripts can inspect $?.
