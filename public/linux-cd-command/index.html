What does cd do?

It changes the shell's current working directory. Relative paths are interpreted from this location.

Step-by-step process

  1. Run pwd to see where you are.
  2. Use ls to inspect available directories.
  3. Run cd directory.
  4. Run pwd again to verify the move.
pwd
ls
cd projects
pwd

Important path examples

cd /        # root directory
cd ~        # home directory
cd ..       # one level up
cd -        # previous directory
cd projects # relative path

Absolute paths begin from root; relative paths begin from your current directory.

Common mistakes

  • Forgetting spaces or special characters in directory names may require quoting.
  • Assuming cd changes another terminal window—it only changes the current shell.
  • Working relative to the wrong directory because pwd was not checked.
