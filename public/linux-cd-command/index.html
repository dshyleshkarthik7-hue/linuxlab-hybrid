What does cd do?

The cd command changes your current working directory.

cd /etc
cd ..
cd ~
cd projects

Common examples

  • cd / — go to the root directory
  • cd .. — move up one directory
  • cd ~ — go to your home directory
  • cd folder — enter a folder
