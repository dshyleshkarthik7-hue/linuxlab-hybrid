Open-source Linux images used by LinuxTerminal

The browser VM path uses pinned Linux artifacts and verifies the complete artifact before exposing it to the VM loader.

Alpine Linux

Alpine Linux is the lightweight distribution used for the real browser environment.

Alpine Linux official site ↗

Linux4

Linux4 is the project's browser-oriented Linux image path used by VM integration. Artifact identity is pinned rather than inferred from a filename.

Integrity

The verified loader requests the complete artifact, computes SHA-256, compares it with the pinned digest and fails closed on missing or mismatched verification. Partial responses cannot establish the digest of the complete image.
