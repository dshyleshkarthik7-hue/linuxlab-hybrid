QUICK GUIDE

Start here

After Alpine reaches its login screen, try these exercises in order.

1. Inspect the system

uname -a, whoami, pwd

2. Explore files

ls, cd /tmp, mkdir lab, cd lab

3. Create and read

printf 'hello\n' > note.txt, then cat note.txt

4. Practice safely

Use man and the site's command lessons when you are unsure.

5. Reset when needed

Use ↺ Reboot for a fresh Developer Alpine session.

6. Continue learning

Open the Linux lessons or career guide.
