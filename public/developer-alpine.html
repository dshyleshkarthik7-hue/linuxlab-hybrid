CAREER OPPORTUNITIES

Where Linux skills can take you

Linux Administrator

Manage servers, users, software, storage, updates and day-to-day system health.

Cloud Engineer

Work with Linux-based cloud machines, networking, storage and reliable deployments.

DevOps Engineer

Connect development and operations with automation, delivery pipelines and infrastructure tools.

Site Reliability Engineer

Help keep important services reliable, observable and ready to scale.

Cybersecurity

Build foundations in system permissions, logs, networking and secure administration.

Platform Engineer
