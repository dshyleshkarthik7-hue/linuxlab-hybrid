QUICK GUIDE

Start here

Once Alpine finishes booting, try these small exercises in order. Use Tab to complete commands and Ctrl+L to clear the terminal.

1. Inspect the system

Run uname -a, whoami, and pwd to see the kernel, current user, and working directory.

2. Explore files

Run ls, cd /tmp, mkdir lab, and cd lab to practice navigation.

3. Create and read

Run printf 'hello\n' > note.txt and cat note.txt to practice redirection and file reading.

4. Practice safely

Use man or the site's command lessons when you are unsure what a command does.

5. Reset when needed

Use ↺ Reboot to return to a fresh Alpine session if an experiment gets messy.

6. Continue learning

Open the Linux lessons for structured practice or the career guide separately.
