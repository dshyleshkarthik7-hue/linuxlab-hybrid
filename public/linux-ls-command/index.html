What does ls do?

It lists directory contents. Options change how much metadata and which files are shown.

Step-by-step process

  1. Run ls for a basic listing.
  2. Run ls -l to inspect permissions and metadata.
  3. Run ls -a to include hidden entries.
  4. Combine options with ls -la.
ls
ls -l
ls -a
ls -la /etc

Understanding the output

Long listings expose permissions, ownership, size, and timestamps. Read each column rather than treating it as decoration.

Common mistakes

  • Assuming hidden files are absent when -a was not used.
  • Confusing a file name with a full path.
  • Deleting based on an unchecked listing.
