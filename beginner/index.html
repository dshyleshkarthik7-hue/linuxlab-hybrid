What is Linux, and how can you use it?

Linux is an operating system, like Windows or macOS. You can learn it without deleting Windows or changing your computer.

🌐 LinuxTerminal in your browser

The easiest first step. Learn commands safely, explore the sandbox and later try real Linux without installing anything.

💻 VirtualBox

Run Linux inside a window while keeping your current operating system. We recommend Oracle VM VirtualBox for beginners.

Get Oracle VM VirtualBox ↗

🔀 Dual boot

Keep your existing operating system and Linux on the same computer, then choose one when the computer starts. Back up important files first.

🖥️ Full Linux installation

Use Linux as your main operating system when you are comfortable with installation, updates, backups and recovery.
