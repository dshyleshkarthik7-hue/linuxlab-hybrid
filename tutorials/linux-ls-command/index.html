Linux ls Command: Options, Examples and File Listings

Learn the Linux ls command with practical examples for long listings, hidden files, readable sizes, sorting, and safe directory inspection.

What does ls do?

ls lists directory entries. The exact output depends on the path, permissions, locale, and whether the system uses GNU coreutils, BusyBox, or another implementation.

Start with these examples

ls
ls -l
ls -a
ls -lh
ls -lt
ls -la /etc
  • ls: list visible entries in the current directory.
  • ls -l: use a long listing with permissions, owner/group, size, and modification time.
  • ls -a: include names beginning with a dot, including . and ...
  • ls -lh: display sizes in human-readable units where supported.
  • ls -lt: sort by modification time, newest first on common GNU/Linux implementations.

Read a long listing

-rw-r----- 1 alice developers 2.1K Oct 18 12:00 notes.txt

The first field contains the file type and permission bits; the link count follows; then owner, group, size, timestamp, and name. Symlinks and directories have different first characters and behavior.

Common mistakes

ls output is not a complete security audit. Hidden files are not necessarily secret, and a file's displayed permissions alone do not show ACLs, mount options, or every access-control layer. Use stat for detailed metadata and inspect ACLs when relevant.

Practice safely

Try these commands in a directory you own, such as your home directory. Listing commands do not change files.

pwd
ls -la
ls -lh /etc
