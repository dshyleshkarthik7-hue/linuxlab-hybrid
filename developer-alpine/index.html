What happens when you run a command?

  1. The terminal sends your keystrokes to the emulated guest.
  2. Alpine's shell parses the command into a program invocation, arguments, redirections and pipelines.
  3. The selected program requests kernel services through system calls such as openat, read, write, execve or wait4, depending on the command.
  4. The emulated CPU, memory, devices and kernel execute those operations inside v86; the browser does not execute the guest command as a host shell command.
  5. Guest output travels back through the emulated serial/device path to xterm for display.
