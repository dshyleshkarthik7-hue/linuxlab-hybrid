ISO sources and integrity

LinuxTerminal uses pinned VM images so the browser loader can verify the complete artifact before handing it to the emulator.

Alpine Linux

Developer Alpine and Alpine Virt 3.24.1 are supported profiles. The project records expected SHA-256 digests and verifies the complete artifact before use.

Source project: Alpine Linux

Linux 4

LinuxTerminal also provides an ultra-light Linux 4 profile. Its release artifact is pinned and verified before the emulator consumes it.

Image label: linux4.iso

Integrity model

Large images may be downloaded using validated HTTP range requests. Each downloaded artifact is assembled, size-checked and SHA-256 verified before it is returned to the VM loader.

The ISO relay is an artifact-delivery mechanism, not a guest-network or host-security boundary.

Repository

The build scripts, integrity implementation and release metadata are maintained in the LinuxTerminal source repository.
