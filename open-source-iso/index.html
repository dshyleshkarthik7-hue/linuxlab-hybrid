Open-source ISO sources

LinuxTerminal uses pinned VM images so the browser loader can verify the complete artifact before handing it to the emulator.

Alpine Linux

Developer image and Alpine Virt 3.24.1 are supported profiles. The project records the expected SHA-256 digest in its integrity module and verifies the complete downloaded artifact before use.

Source project: Alpine Linux

Linux 4

LinuxTerminal also provides an ultra-light Linux 4 profile for browser practice. Its release artifact is pinned by SHA-256 before the emulator consumes it.

Image label: linux4.iso

Integrity model

Range requests to the verified ISO relay are rejected. The browser fetch layer removes partial-range requests, downloads the complete artifact, verifies SHA-256, caches the verified bytes and only then returns them to the VM loader.

Never treat the ISO relay as a security boundary for secrets or guest networking.

Repository

The build scripts, integrity implementation and release metadata are maintained in the LinuxTerminal source repository.
