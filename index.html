LINUX 101

What is Linux?

Linux is the open-source kernel that powers operating systems and devices. A Linux distribution combines the kernel with user-space tools, libraries, package management and applications.

The shell interprets commands. Programs request kernel services through system calls, while the kernel manages processes, memory, filesystems and hardware access.

WHY LEARN IT?

Why is Linux worth learning?

Linux skills are useful for software development, cloud computing, servers, containers, DevOps, networking and security. The command line also teaches transferable ideas such as files, processes, permissions, standard input/output and automation.
