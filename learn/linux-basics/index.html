What is Linux?

Linux is a family of operating systems built around the Linux kernel. A distribution combines that kernel with system software, package management, libraries, applications and defaults.

Kernel vs distribution

The kernel manages hardware and provides core services such as processes, memory and device access. A distribution packages the kernel with the rest of a usable operating system. Ubuntu, Debian, Fedora and Alpine are examples of distributions.

Why learn Linux?

  • Linux powers a large part of cloud and server infrastructure.
  • The command line makes repeatable administration and automation possible.
  • Open tools make it useful for development, containers, research and security education.
Key idea: “Linux” can refer to the kernel or, in everyday conversation, an entire Linux distribution. Context tells you which meaning is intended.

Your first terminal commands

pwd
ls
whoami
uname -s

pwd shows the current directory, ls lists entries, whoami prints the current user, and uname reports system information.
