A guided Linux learning path

1. Linux basics

Understand Linux, distributions, the kernel, terminal and why the command line matters.

2. Terminal navigation

Master pwd, ls, cd and paths without guessing.

3. Files & directories

Create, copy, move, inspect and safely remove files and directories.

4. Text processing

Search and transform text with pipes, grep, sort, cut and friends.

5. Linux permissions

Read permission bits and understand chmod, ownership and least privilege.

6. Processes & resources

Inspect processes and system resources, then understand signals and jobs.

7. Shell scripting

Build small Bash scripts with variables, conditions, loops, functions and exit codes.

How to use the tutorials

  1. Read the concept and predict what a command should do.
  2. Run the example in the LinuxTerminal simulator.
  3. Change one argument and observe what changes.
  4. Use the related command page, challenge and quiz to check your understanding.
Learning tip: Do not memorize every option. Learn the purpose of a command, read its help, and practice combining a few commands.
